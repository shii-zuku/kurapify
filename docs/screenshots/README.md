# Screenshots

The main README shows these files. Put your own pictures here with these names (PNG, about 1500 px wide is plenty):

| File | What to show |
|---|---|
| `now-playing.png` | The full-screen player with the blurred cover behind the lyrics. The hero image at the top of the README |
| `home.png` | Home |
| `album.png` | An album page, tinted by its cover |
| `lyrics.png` | Lyrics with translation turned on |
| `video.png` | A music video with lyrics and comments over it |

Until a file is here, its slot in the README shows as a broken image. Delete this file once the pictures are in, or keep it.
